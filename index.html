Steel Base Replacement Matrix

ULTRA-SR™

Precision polyester-base replacement matrix designed for compatibility with steel-based matrix products.

Stable, Durable and Easy to Identify

Steel-base compatibility without corrosion

ULTRA-SR™ is a polyester-base replacement product with the same base thickness as steel-based matrix and is designed to be compatible with steel-based products on the market.

A specially formulated adhesive supports maximum impressions, while high-impact plastic provides stability and durability. The base and locator have sizes printed on for easy identification, and all products are supplied with finger-lift tape as standard.
